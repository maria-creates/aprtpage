# привет, дружок!

Статический сайт для гостей в Петербурге. Мобильная версия, фотографии, интерактивная 3D-модель дивана, ссылки на Telegram, РЖД и Яндекс Карты.

## Запуск

Сборка и установка зависимостей не нужны. Вся страница и ее ресурсы находятся в `dist`. Для локального просмотра:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует `dist` при изменении ветки `main` и по ручному запуску. Сайт не использует сервисы ChatGPT, ключи API или серверную часть. Все фотографии, модель, просмотрщик и декодер 3D хранятся локально; внешние ссылки открываются отдельно.

`dist/gallery.json` задает порядок, пропорции, фотографии и заглушки. Фотографии находятся в `dist/assets`.
